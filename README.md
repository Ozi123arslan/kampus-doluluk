# Kampüs Doluluk

YTÜ Davutpaşa kampüsündeki kafe, yemekhane ve spor salonunun anlık doluluğunu gösteren Flutter uygulaması. Öğrenciler mekandayken tek dokunuşla "boş / orta / dolu" bildirir, bildirimler zamana göre ağırlıklandırılıp birleştirilir ve herkese canlı yansır.
